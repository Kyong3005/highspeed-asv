# highspeed-asv

Project page for **High-Speed ASV Control** — path following of a planing-hull autonomous surface
vehicle (up to 48 knots) with a speed-scheduled surge feedforward model and LOS guidance.
KAIST MORIN Lab.

Static site (`index.html` + `assets/`). Published at https://kyong3005.github.io/highspeed-asv/.
